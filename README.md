# 🧠 Personality Quiz Game (16 Personalities Inspired)

A Python-based personality quiz game built using Tkinter, designed to analyze user responses and provide a personality outcome.

---

## 📌 Overview

This project is a GUI-based personality test inspired by the concept of the **16 Personalities model**.  
It was developed as a school project to explore how user inputs can be used to simulate personality classification.

The system presents a set of carefully structured questions and evaluates responses to determine a personality type.

---

## ⚙️ Features

- 🧠 16 personality-based outcomes  
- ❓ 16 structured questions for analysis  
- 🖥️ Interactive GUI using Tkinter  
- 🎯 Simple and smooth user flow  
- 📊 Logic-based personality evaluation  

---

## 🛠️ Tech Stack

- **Python**
- **Tkinter** (GUI)

##  📦 Requirements
	•	Python 3.x
	•	Tkinter (comes pre-installed with Python)

⸻

##  🧪 How It Works
	•	Users answer a series of 16 questions
	•	Each answer contributes to personality scoring
	•	Final output is mapped to a personality type

⸻

##  ⚠️ Disclaimer

This project is a mock implementation inspired by the 16 personalities concept.
It is intended for learning and demonstration purposes only and does not represent scientifically validated results.
